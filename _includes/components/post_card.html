{%- comment -%} A "post box": thumbnail + eyebrow + title + blurb + tags, wrapped in one card-wide link. Used by the section index pages in place of a bullet list. Normally you do not call this directly: components/children_nav.html renders one card per child page from that page's own `card_*` front matter, so a section index lists itself. Call it by hand only for a one-off card. Parameters href (required) URL the whole card links to. title (required) Card headline. Deliberately not a heading — the "On this page" panel is built from rendered h2/h3, and card titles are navigation, not part of the page outline. eyebrow Small uppercase accent line above the title (venue, chapter, …). excerpt One- or two-sentence blurb. tags Comma-separated list; each item is rendered as a "#tag" chip. media Thumbnail treatment: "cover" (default) fills the frame, "device" floats a portrait app screenshot over a tinted panel, "glyph" draws a numeral/monogram. With no `image` or `video` to show, "glyph" is used regardless, so a card added without artwork still gets a cover instead of a hole in the grid. image Site-absolute image path, e.g. "/assets/images/foo.png". video Site-absolute video path; used instead of `image` when given. alt Alt text for `image`. Cards are decorative next to their own title, so this defaults to empty rather than repeating it. glyph Text drawn by the "glyph" treatment (e.g. "01"); defaults to the title's first character. {%- endcomment -%} {%- assign media = include.media | default: "cover" -%} {%- if include.image == nil and include.video == nil -%}{%- assign media = "glyph" -%}{%- endif -%} {%- if include.glyph -%} {%- assign glyph = include.glyph -%} {%- else -%} {%- assign glyph = include.title | slice: 0 | upcase -%} {%- endif -%} {%- if media == "glyph" -%} {{ glyph }} {%- elsif include.video -%} {%- else -%} {%- endif -%} {%- if include.eyebrow -%}{{ include.eyebrow }}{%- endif -%} {{ include.title }} {%- if include.excerpt -%}{{ include.excerpt }}{%- endif -%} {%- if include.tags -%} {%- assign tag_list = include.tags | split: "," -%} {%- for tag in tag_list -%}#{{ tag | strip }}{%- endfor -%} {%- endif -%}
