# 플랜티넷 | AI Engineer

2025년 2월부터 플랜티넷에서 **AI Engineer**로 영상 분석과 LLM 기반 AI 서비스를 프로덕션에 적용하는 일을 하고 있습니다.

## 담당 업무

- 영상 프레임 분석 기반 얼굴 딥페이크 탐지 시스템을 개발·최적화하고, 지역 교육청을 위한 Android 온디바이스 환경에 배포했습니다.
- 매거진 기사 요약·번역·키워드 추출을 자동화하는 LLM 기반 AI Agent 서비스와 API 서버를 개발·운영했습니다.
- 기사 데이터 전처리, 임베딩, 인덱싱 파이프라인을 구축하고 vector search와 Agent 워크플로를 결합한 Agentic RAG 챗봇을 개발했습니다.
- 매거진 스캔 이미지에서 콘텐츠를 추출·구조화해 네이버 지식백과 형식으로 변환하는 멀티모달 문서 자동화 Agent를 개발했습니다.
- AI 모델 서빙, vector database, 배치 파이프라인, 백엔드 서버의 배포와 모니터링, 장애 대응을 수행하고 있습니다.

## 주요 분야

On-device Deepfake Detection, LLM, AI Agent, Agentic RAG, Vector Search, Multimodal Document Automation, LLMOps
